# Customer Churn Prediction (Machine Learning Project)

This is a simple end-to-end Machine Learning project that predicts whether a customer will churn (leave the service) or stay. The model is trained on a real dataset of 7,000+ customers and deployed using Streamlit.



## 🔍 What this project does
- Loads customer data  
- Cleans and processes the dataset  
- Converts categorical columns into numeric format  
- Trains a Logistic Regression model  
- Achieves ~78% accuracy (without tuning)  
- Provides a Streamlit app for live predictions
